## Ambiguities

- **Quote** (Foundation > Rich Text): section uses `<pkts-icon>` as decoration
  inside a branded `<blockquote>`. Excluded from List A since it technically
  contains a pkts-* element, but the main feature is CSS-only blockquote styling.
- **tab.css vs PktsTabs**: `tab.css` likely styles the individual `<li>` tab item
  inside `pkts-tabs`. It may not need its own standalone web component — noted as
  "unsure" in List B.
- **Data Table (line 238) vs DataTable (line 248)**: tearsheet-1 has two adjacent
  sections. Line 238 is a stub; line 248 (`DataTable`) is the live demo of
  `pkts-data-table`. Treated as stub above.
- **Input Label**: has a Figma entry (`9764:13833`) but no `<h2>` section found
  in any tearsheet page. May have been removed from tearsheet-1.
